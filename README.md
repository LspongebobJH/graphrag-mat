# GraphRAG Materials Knowledge-Graph Notes

This repository is a compact research library for AI4Materials knowledge graphs, GraphRAG, and literature-based materials discovery. It contains project notes, schema and pipeline comparisons, and locally saved paper copies in PDF and readable HTML form.

## Research notes

The important files are `construction_pipeline_2026-10-15.md` and `schemas_2026-10-15.md`

|---|---|

| [summary_2026-10-12.md](summary_2026-10-12.md) | Plain-language comparison of the projects' entities, relations, sources, provenance, and retrieval methods. |
