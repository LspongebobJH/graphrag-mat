<summary>1. Existing GraphRAG Methods and Implementations</summary>


| Framework | Main capability | Code / documentation |
|---|---|---|
| **Microsoft GraphRAG** | Entity graphs, community detection, and global/local search | [Paper](https://arxiv.org/abs/2404.16130) · [GitHub](https://github.com/microsoft/graphrag) |
| **Neo4j GraphRAG** | Vector, hybrid, and graph retrieval pipelines | [Python repo](https://github.com/neo4j/neo4j-graphrag-python) · [Docs](https://neo4j.com/docs/neo4j-graphrag-python/current/) |
| **LlamaIndex Property Graph** | Entity and relation extraction with property-graph querying | [GitHub](https://github.com/run-llama/llama_index) · [Docs](https://docs.llamaindex.ai/en/stable/module_guides/indexing/lpg_index_guide/) |
| **LangChain Graph QA** | Graph databases and Cypher-based question answering | [GitHub](https://github.com/langchain-ai/langchain) · [Docs](https://python.langchain.com/docs/integrations/graphs/) |
| **LightRAG** | Lightweight graph construction and dual-level retrieval | [Paper](https://arxiv.org/abs/2410.05779) · [GitHub](https://github.com/HKUDS/LightRAG) |
| **HippoRAG** | Graph-based associative retrieval for multi-hop questions | [Paper](https://arxiv.org/abs/2405.14831) · [GitHub](https://github.com/OSU-NLP-Group/HippoRAG) |
